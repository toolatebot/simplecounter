Возможности:

- Материальный стиль интерфейса Material 3 на Jetpack Compose
- Установка значения по умолчанию для счётчика для его быстрого сброса
- Разрешение или запрет отрицательных значений для счётчика
- Пометка счётчиков метками и фильтрация счётчиков по меткам
- Открытие счётчиков в полноэкранном режиме
- Использование клавиш регулировки громкости для изменения значения счётчика в полноэкранном режиме
- Возможность компактных карт счётчиков
- Резервное копирование счётчиков и меток в формате JSON и их восстановление

Используемые библиотеки:

- AndroidX (Compose, Lifecycle, Room, DataStore, AppCompat, Navigation)
- Google Accompanist
- Moshi
